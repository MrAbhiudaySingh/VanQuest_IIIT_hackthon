VanQuest Achievement Pop-up Frontend

Open index.html in a modern browser. No installation, backend, database, or network connection is required.

Included:
- Animated achievement toast that slides down from the top
- Small confetti effect on unlock
- 43 sample achievements across life milestones, education, money management, choices, investing, safety, and hidden/funny outcomes
- Preview any achievement or unlock it in the local demo
- Achievement collection with rarity filters
- XP and unlock counters
- Responsive dark pixel-RPG-inspired styling

This is a front-end prototype only. Unlock state resets when the page is refreshed. Connect to your game's event/state system and persistent storage for production use.
