VanQuest Financial Journey Setup — Frontend Demo

Files:
- index.html: standalone responsive onboarding quiz.

How to run:
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. Answer the 10 questions and review the journey profile.

This is a front-end prototype only:
- No backend or database connection.
- Answers remain in browser memory while the page is open.
- Completing the flow downloads a JSON file containing the answers.
- No real financial information is required.
- Age target feasibility is framed as a planning prompt, not a judgement or investment recommendation.

To integrate into a real app, connect the final profile object in finish() to your approved backend/API and apply appropriate privacy/security controls.
